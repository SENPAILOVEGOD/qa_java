#### Unit_tests_java
🐾 **Проект по автоматизации тестирования на Java**

Это учебный проект, цель которого - написание юнит-тестов с использованием JUnit 4, Mockito и JaCoCo для проверки покрытия кода.

## 📚 Содержание

* Технологии

* Структура проекта

* Установка и запуск тестов

* Отчёт о покрытии (JaCoCo)

* Авторы

## 🛠 Технологии
* Java 11 (Amazon Corretto)

* Maven (управление зависимостями и сборка)

* JUnit 4.13.2 – фреймворк для тестирования

* Mockito 4.6.1 – создание мок-объектов

* JaCoCo 0.8.15 – оценка покрытия кода тестами

Все зависимости указаны в `pom.xml`.

## ⚙️ Установка и запуск тестов

1. Клонируйте репозиторий:

```bash
git clone https://github.com/SENPAILOVEGOD/Unit_tests_java.git
cd Unit_tests_java
```
2. Выполните сборку и запуск всех тестов с генерацией отчёта о покрытии:

```bash
mvn clean verify
```

Эта команда:

* скомпилирует проект,

* запустит все тесты (JUnit + Mockito),

* сгенерирует отчёт JaCoCo в папке target/site/jacoco/.

## 📊 Отчёт о покрытии (JaCoCo)

После выполнения mvn clean verify откройте в браузере файл:

```text
target/site/jacoco/index.html
```

Вы увидите детальную статистику покрытия кода тестами для каждого класса.

> Примечание: если вы хотите только запустить тесты без генерации отчёта, используйте `mvn clean test`. Для получения отчёта обязательно выполните `mvn clean verify` после тестов.
